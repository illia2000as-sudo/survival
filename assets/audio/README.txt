Необязательные записи для кат-сцен DeadZone.
Если положить сюда файл с нужным именем, игра возьмёт его вместо синтезированной заглушки. Без файлов всё работает.

  siren.mp3          воздушная тревога (зарезервировано; сейчас сирена синтезируется)
  intro_radio.mp3    голос диктора для вступления: полный текст из scenes/intro.js (INTRO_LINES), без пауз между фразами
  finale_radio.mp3   голос диктора для финала: scenes/finale.js (FINALE_LINES)

Субтитры подгоняются под длину записи по числу символов в каждой фразе.
Пока записей нет, диктор читает текст голосом браузера (русский, если он установлен в системе),
а если голоса нет - играет «бормотание» через радиофильтр.

Что ещё можно заменить своим:
  * модели людей: scenes/people.js (build(kind, seed, pose) должен возвращать { group, legL, legR, update })
  * квартира: функция buildRoom() в scenes/intro.js
  * площадка эвакуации: функция buildSite() в scenes/finale.js
