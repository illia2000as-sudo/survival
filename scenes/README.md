# Кат-сцены DeadZone (папка `scenes/`)

Вступление «Начало конца» и финал «Эвакуация». Подключаются одной строкой в `main.js`
(`import { initCutscenes } from './scenes/index.js'`), игровые механики не затронуты.

| Файл | Что делает |
|---|---|
| `index.js` | точка входа: `initCutscenes(G)`, отдаёт `startIntro`, `update`, `serialize`, `restore` |
| `intro.js` | квартира, пробуждение, ходьба по комнате, радио, окно, титры DEADZONE |
| `finale.js` | объявление по радио, точка эвакуации с военными, карта и маркер, посадка, отъезд, «ВЫ ВЫЖИЛИ», меню |
| `people.js` | модели-заглушки: солдаты, офицер, выжившие, герой, силуэты заражённых |
| `audio.js` | сирена, ветер, далёкий город, радио, голос диктора, мотор, музыка титров (всё синтезируется) |
| `ui.js` | затемнение, веки, субтитры, подсказки, титры, кнопки, чёрные полосы |

## Как это работает

* **Вступление** запускается кнопкой «Новая игра» (только одиночная игра). Пропуск: кнопка «Пропустить» справа внизу или **Enter**.
  В адрес можно добавить `?nointro`, чтобы вступления не было совсем.
  Ходьба WASD, мышь, **E** - включить радио / выглянуть в окно. После титров игра стартует в 6:24 утра первого дня.
* **Финал** срабатывает один раз: когда наступило утро 15-го дня (прошло 14 полных игровых дней), игрок жив, не в подвале и не в мультиплеере.
  Радио объявляет эвакуацию, в углу появляется мини-карта, на экране маркер «ЭВАКУАЦИЯ N м», **M** открывает большую карту.
  Точка эвакуации стоит на конце одной из четырёх дорог (какая именно - зависит от зерна мира). У грузовика нажми **E**.
  После финала меню: «Продолжить игру», «Новая игра», «Выход в главное меню».
* **Управление** на время сцен: пока идёт кат-сцена, игровое время стоит, ввод игры и пауза по Esc отключены (`cutscenes.cut.active` в `main.js`).
* **Сохранения**: в слот пишется поле `evac` (0 - не было, 1 - объявлено, 4 - завершено). Завершённый финал не повторится.

## Что менять в `main.js`, если захочется подкрутить

* `startNewGame()` - как запускается вступление и в какое время суток начинается игра.
* блок `const cutscenes = initCutscenes({...})` в конце файла - какие данные игры видят сцены.

Звуковые и графические заглушки описаны в `assets/audio/README.txt`.
