# Город (папка `world/`)

`city.js` - `buildCity(G)` строит жилой район и возвращает точку появления игрока. Вызывается один раз в конце создания мира из `main.js`
(после озёр и дикой местности, перед `initDone`), поэтому остальные части мира из старых сохранений не сдвигаются.

* Дома ставятся на сетку улиц вокруг центра: до 26 штук, только там, где нет других построек, предметов-куч и оружейных кейсов. Рядом с концами дорог (площадка эвакуации) город не строится.
* Дом: 4-5 этажей, подъезд с двухмаршевой лестницей, по две квартиры на этаж, мебель, окна с рамами и шторами, балконы, крыша с надстройками, фонари, машины, баки.
* Столкновения: стены и мебель, как обычно, в `colliders`; верхние этажи ходятся по `floors`; для мебели и стен верхних этажей добавлено поле `bottom` (препятствие действует только для тех, кто стоит не ниже этого уровня).
* Запасы в квартирах: еда, вода, аптечки, патроны (фиксированные места, не возрождаются). Зомби расставлены по улицам и первым этажам.
* Новая игра начинается в квартире на втором этаже ближайшего к центру дома (`spawnPoint` в `main.js`).
* Число домов, размеры и состав - константы в начале файла (`MAXB`, `HX`, `HZ`, `FH`).
